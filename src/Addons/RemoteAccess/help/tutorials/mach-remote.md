# Control the laser from your phone
<!-- category: Machine and settings -->
<!-- summary: Start the remote server and connect your phone, to watch, load and start jobs from it. -->
<!-- page: remote.md#setting-it-up -->
<!-- order: 90 -->
Your phone can show what the laser is doing, take pictures, pause and stop, and load and start your
designs, through this computer. Connect to the machine from PhotonCanvas once first, so the connection
keys are set up.

## Open Remote access
<!-- target: ribbon:Laser/Remote access -->
<!-- wait: window:Remote access -->
Click **Remote access** on the **Laser** tab.

## Start the server
<!-- target: button:Start server -->
Click **Start server**. If Windows asks whether PhotonCanvas Server may use the network, allow it on
private networks.

## Scan the QR code
<!-- target: text:Scan the code -->
On the phone (on the same Wi-Fi), point the camera at the QR code and open the link. The page opens
connected. Add it to the home screen to open it like an app.

## Choose where your designs are
<!-- target: button:Add folder -->
The phone lists your recent designs. Click **Add folder…** to add a folder whose designs it should
list too.

## Decide whether the phone may start jobs
<!-- target: button:Allow starting jobs from the phone -->
Starting jobs from the phone is off at first: the phone can load a job and you press the machine's
button. To start from the phone too, tick **Allow starting jobs from the phone** and read the warning
before you accept it.

## Start a job from the phone
<!-- target: window:Remote access -->
On the phone, tap a design under **Designs**, check it, and tap **Load onto machine**. Look at the
picture of the bed it takes. Then press the machine's button, or, if you allowed it, tap **Start
job**. The laser fires, so look properly first.
