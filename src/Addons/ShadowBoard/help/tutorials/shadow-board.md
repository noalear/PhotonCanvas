# Make a shadow board
<!-- category: Materials and tests -->
<!-- summary: Lay your tools on the bed and make a drawer insert with a pocket, a finger notch and a label for each. -->
<!-- page: shadow-board.md -->
<!-- order: 60 -->
A shadow board gives every tool its own pocket, so a missing one shows at once. The camera outlines
the tools where they lie, so lay them on the bed the way you want them in the drawer. You need a
connected machine with a calibrated camera.

## Open the shadow board maker
<!-- target: ribbon:Laser/Shadow board -->
<!-- wait: window:Shadow board -->
Click **Shadow board** on the **Laser** tab.

## The tools' height
<!-- target: field:Distance (mm) -->
Enter the distance from the laser to the surface the tools lie on, so the photo lines up.

## Find them
<!-- target: button:Take photo and find tools -->
The camera takes a photo and outlines each tool. The head doesn't move and the laser stays off.

## Name them
<!-- target: field:Made as -->
Type each tool's name in the list: it's engraved by its pocket. Then choose stacked sheets or one
engraved board.

## Depth and gap
<!-- target: field:Depth (mm) -->
Set how deep the tools sit, and the **Gap** round them so they drop in.

## Make it
<!-- target: button:Make the board -->
The board goes on new pages, all in the same place: run each sheet's page in turn, then glue the
stack.
