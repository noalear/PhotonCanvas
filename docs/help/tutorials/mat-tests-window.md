# Find the right test
<!-- category: Materials and tests -->
<!-- summary: Every test is in one window: pick one from the list, see what it finds out, and open it. -->
<!-- page: materials-and-tests.md#the-tests-window -->
<!-- order: 5 -->
There's one **Tests** button for all the tests: the test grid, the cut test, the etch rate, the
tone and line tests and the rest. This shows how to find the one that answers your question.

## Open the Tests window
<!-- target: ribbon:Materials & Tests/Tests -->
<!-- wait: window:Tests -->
Click **Tests** on the **Materials & Tests** tab.

## Pick a test
<!-- target: field:Test -->
Open the **Test** list and pick one. The tests are grouped by what they're for: finding the
settings, pictures, colour on metal, using your results, machine checks.

## Read what it does
<!-- target: window:Tests -->
Under the list, the window says what the test finds out and what it needs. Not sure which one?
[Which test answers which question](materials-and-tests.md#which-test-answers-which-question)
has a table.

## Open it
<!-- target: button:Open -->
Click **Open**. The test's own window opens; the Tests window remembers it for next time.
