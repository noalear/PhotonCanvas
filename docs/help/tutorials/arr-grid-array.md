# Grid array
<!-- category: Arranging -->
<!-- summary: Copies of the selection in rows and columns, with a set gap. -->
<!-- page: arrange.md#grid-array -->
<!-- order: 60 -->
A grid array lays out copies in rows and columns: a batch of tags, coasters or test pieces. The
copies show on the work area as you set the numbers.

## Select what to copy
<!-- target: canvas -->
<!-- wait: selection -->
Select the shape or group to repeat.

## Open Grid array
<!-- target: ribbon:Arrange/Grid array -->
<!-- wait: window:Grid array -->
Click **Grid array**.

## Columns and rows
<!-- target: field:Columns -->
Set **Columns** and **Rows**. The original stays as the top-left copy.

## The gaps
<!-- target: field:Gap across (mm) -->
**Gap across** and **Gap down** are the space between copies, in mm.

## Make them
<!-- target: button:Make copies -->
<!-- wait: closed:Grid array -->
Click **Make copies**. The original and the copies are selected.
