# Picture rows and passes
<!-- category: Layers and settings -->
<!-- summary: Hide the rows a picture is burned in: direction, several turned passes, crosshatch and pass-through. -->
<!-- page: layer-settings.md#picture-more-settings -->
<!-- order: 200 -->
A picture is burned row by row, and the rows can show: shifted against each other, or darker where
the heat built up. These settings change how the rows are laid down. You need a picture on a
Picture layer (Import → **Picture** imports one).

## Select the picture
<!-- target: canvas -->
<!-- wait: picture-selected -->
Click the picture. Its layer's settings show in **Layer settings**.

## One way or both
<!-- target: button:Burn rows in both directions -->
Under **More settings**, **Burn rows in both directions** is on to start. Off, every row burns left
to right: slower, but rows can't be shifted against each other.

## Several turned passes
<!-- target: panel:Layer settings -->
Set **Passes** to 2 or 3, then, among the picture settings, **Turn per pass (°)** to an odd angle
like 37°. Lower the power so all the passes together give the darkness you want.

## Crosshatch
<!-- target: button:Crosshatch (each pass twice, the second turned) -->
Tick **Crosshatch (each pass twice, the second turned)**. The line under it spells out every burn
and its angle.

## The file's own pixels
<!-- target: button:Pass-through (the file's own pixels) -->
For a picture already prepared at the right size, tick **Pass-through (the file's own pixels)**:
one dot per pixel, never denser than the **Resolution**.

## Compare on scrap
Materials & Tests → Tests → **Line test** (from the Material tests add-on) burns the same patch with one change each, side by side.
