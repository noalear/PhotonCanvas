# Save and open designs
<!-- category: Importing and exporting -->
<!-- summary: Save a design, open it again, and start a new one. -->
<!-- page: files.md#designs-new-open-and-save -->
<!-- order: 50 -->
A design file keeps everything: pages, layers with their settings, shapes, text and pictures.
Save it to come back to it, and to keep its earlier versions.

## Save it
<!-- target: header:Save -->
Click the disk icon (`Ctrl+S`). The first time, choose a folder and a name in the window that opens.

## The title shows what's saved
A **•** after the design's name in the window's title means there are changes not yet saved.

## Open a recent design
<!-- target: header:File -->
Click **File** and point at **Open recent**: the last 10 designs you opened or saved. **Open…** (`Ctrl+O`) finds any other.

## Start a new design
<!-- target: header:File -->
**File → New** (`Ctrl+N`) starts an empty one. If the design on screen has unsaved changes, you're asked whether to save them first.

## Closing is safe
When you close the program, the open design comes back at the next start, at the same view. Unsaved changes are copied aside every two minutes, in case it stops unexpectedly.
