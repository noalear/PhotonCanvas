# Draw polygons and stars
<!-- category: Drawing -->
<!-- summary: Draw polygons and stars with any number of sides or points, and change them later. -->
<!-- page: drawing.md#polygon-and-star -->
<!-- order: 40 -->
Polygons and stars with 3 to 64 corners or points, from triangles to sunbursts. They stay editable,
so the sides, points and depth can be changed after drawing.

## Choose the Polygon
<!-- target: ribbon:Home/Polygon -->
<!-- wait: tool:Polygon -->
Click the **Polygon** icon on the **Home** tab (or press `O`).

## Set the sides
<!-- target: field:Sides -->
In the bar above the work area, set **Sides**.

## Drag it
<!-- target: canvas -->
<!-- wait: shapes:+1 -->
Drag the box it fills. `Shift` keeps the box square, `Alt` draws from the centre.

## Choose the Star
<!-- target: ribbon:Home/Star -->
<!-- wait: tool:Star -->
Click the **Star** icon (or press `S`).

## Set its points
<!-- target: field:Points -->
Set **Points**, and **Inner size %**: smaller makes thinner, spikier points.

## Drag it
<!-- target: canvas -->
<!-- wait: shapes:+1 -->
Drag the box the star fills.

## Change it later
<!-- target: field:Inner size % -->
With the star selected, the **Selection** panel changes its **Sides / points** and **Inner size %**.
