# Import with a layer per colour
<!-- category: Importing and exporting -->
<!-- summary: Bring in a drawing with each colour on its own layer, ready to set up. -->
<!-- page: files.md#one-layer-per-colour -->
<!-- order: 20 -->
Drawings are often made with a colour per operation: red to cut, blue to score, black to engrave.
Importing by colour puts each colour on its own layer, so each gets its settings in one place.

## Click By colour
<!-- target: ribbon:Import/By colour -->
<!-- wait: shapes:+1 -->
Click **By colour** (`Ctrl+Shift+I`) and choose the drawing in the window that opens.

## See the new layers
<!-- target: panel:Layers -->
Each colour has its own layer, named after the colour's code (*Colour #FF0000*) or the file's own layer name. Layers already there with the same name are reused.

## Set up each layer
<!-- target: panel:Layer settings -->
Click a layer and choose what it does (**Cut**, **Score**, **Engrave**) and its power and speed. New colour layers start as **Cut** with the default settings.
