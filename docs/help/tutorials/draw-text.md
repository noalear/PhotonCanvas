# Add text
<!-- category: Drawing -->
<!-- summary: Put words on the design and set their font, size, curve and width. -->
<!-- page: drawing.md#text -->
<!-- order: 10 -->
Text stays editable: change the words, font or size at any time and the outline is redrawn. Use it
for names, labels and signs, cut out or engraved.

## Choose the Text tool
<!-- target: ribbon:Home/Text -->
<!-- wait: tool:Text -->
Click **Text** on the **Home** tab (or press `T`).

## Click where it goes
<!-- target: canvas -->
<!-- wait: shapes:+1 -->
Click the work area where the text's top-left corner should be. A text saying "Text" appears.

## Type your words
<!-- target: panel:Selection -->
Type in the text box of the **Selection** panel: your words replace "Text". `Enter` starts a new line.

## Pick a font and size
<!-- target: field:Font -->
Choose a **Font**, then set **Size mm**. It's the font size, so capital letters come out a little smaller.

## Bend it
<!-- target: field:Curve (°) -->
Type 90 in **Curve (°)**: each line arches over a quarter of a circle. Negative values curve it down; 0 makes it straight.

## Make it an exact width
<!-- target: field:Fit W -->
**Fit W** scales the text to exactly this width in mm, whatever it says. 0 turns it off.
