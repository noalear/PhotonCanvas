# Number copies
<!-- category: Drawing -->
<!-- summary: Mark several tags in one run, each with the next serial number or spreadsheet row. -->
<!-- page: drawing.md#number-copies -->
<!-- order: 90 -->
Mark several numbered items in one run: copies of a tag, each with the next serial number or
spreadsheet row. Make the copies, then number them.

## Start with a field
<!-- target: canvas -->
You need a text or code with a field such as `{serial}` (see [Mark a serial number](tutorial:draw-serial-numbers)). Group it with its outline (`Ctrl+G`) and select it.

## Make copies
<!-- target: ribbon:Arrange/Grid array -->
<!-- wait: window:Grid array -->
Click **Grid array** on the **Arrange** tab.

## Lay them out
<!-- wait: closed:Grid array -->
Set the rows, columns and gaps and click **OK**. All the copies are selected.

## Number them
<!-- target: ribbon:Home/Number copies -->
Click **Number copies** (the four squares on the **Home** tab). They count row by row from the top, left to right in each row.

## Check them
<!-- target: canvas -->
Each copy now shows its own number. After the run, the serial number moves on past all of them.

## Set one back
To give a copy the design's own number again, select just that copy and click **Number copies**.
