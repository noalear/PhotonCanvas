# Connect to the machine
<!-- category: Machine and settings -->
<!-- summary: Find the machine on your network and connect, automatically or by hand. -->
<!-- page: machine.md#finding-and-connecting -->
<!-- order: 20 -->
PhotonCanvas talks to the machine over your own network. Turn the machine on and make sure it's on
the same network as this computer. Set up the connection keys first (see
[Set up the connection keys](tutorial:mach-connection-keys)).

## Connect
<!-- target: button:Connect -->
Click **Connect** at the right end of the ribbon. It tries the last machine, then searches the
network.

## Allow this computer
<!-- target: panel:Machine -->
The first time, the machine may ask for its button to be pressed to allow this computer. Press it
within 90 seconds.

## Check the status
<!-- target: panel:Machine -->
Connected, the status says *F2 Ultra · Ready* with a green dot, and the camera and focus controls
appear.

## Not found? Open Settings
<!-- target: header:Settings -->
<!-- wait: window:Settings -->
Click the gear at the top right. It opens on the **Machine** page.

## Find it by hand
<!-- target: button:Find machines -->
Click **Find machines**, pick the machine from the list (or type its address) and click
**Connect**.

## Connect at every start
<!-- target: button:Connect automatically when the program starts -->
Leave this ticked to connect each time the program opens.
