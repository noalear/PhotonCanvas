# Export the job
<!-- category: Running jobs -->
<!-- summary: Save the job as the machine's .xf package or as G-code text instead of sending it. -->
<!-- page: running-jobs.md#export -->
<!-- order: 60 -->
Exporting saves the job to a file instead of sending it: the package the machine runs, to keep or
send later, or its G-code as text, to read exactly what the laser will do. Have something in the
design.

## Export the job package
<!-- target: ribbon:Laser/Export .xf -->
Click **Export .xf** and choose where to save it. It's exactly the file **Ship It** uploads.

## Export the G-code
<!-- target: ribbon:Laser/Export G-code -->
Click **Export G-code** for the motion G-code as plain text, to read or check.

## From the job bar
<!-- target: button:Export -->
**Export** in the job bar has the same two choices.
