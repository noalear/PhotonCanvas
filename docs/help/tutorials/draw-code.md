# Add a QR code or barcode
<!-- category: Drawing -->
<!-- summary: Mark a QR code, Data Matrix or barcode, fixed or new on every run. -->
<!-- page: drawing.md#codes -->
<!-- order: 80 -->
Mark a QR code, Data Matrix or barcode. It can hold a web address, or a serial number, the date or
a spreadsheet column that changes on every run.

## Open the code window
<!-- target: ribbon:Home/Code -->
<!-- wait: window:Add a code -->
Click **Code** on the **Home** tab.

## Choose the kind
<!-- target: field:Kind -->
**QR code** is the usual choice. Barcodes such as EAN-13 take digits only.

## Type what it says
<!-- target: field:What it says -->
A web address or any text. **Insert field** adds a serial number or the date, new on every run.

## Set the size
<!-- target: field:Module mm -->
**Module mm** is the size of one square: 0.5 mm is a safe start. The size of the whole code shows under the preview.

## Add it
<!-- target: button:Add code -->
<!-- wait: closed:Add a code -->
Click **Add code**. It goes in the middle of the work area, on an Engrave layer. Double-click it to change it later.
