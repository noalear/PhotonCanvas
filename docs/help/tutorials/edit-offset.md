# Offset an outline
<!-- category: Editing shapes -->
<!-- summary: Draw a new outline a set distance outside or inside a shape. -->
<!-- page: editing-shapes.md#offset -->
<!-- order: 40 -->
Offset draws a second outline at a set distance: a cut line round an engraving, a border round a
sticker, an inset frame. You see it on the work area as you set it.

## Select a shape
<!-- target: canvas -->
<!-- wait: selection -->
With **Select**, click a drawn or imported shape, or a text. Pictures can't be offset.

## Open Offset
<!-- target: ribbon:Home/Offset -->
<!-- wait: window:Offset -->
Click **Offset** (`Ctrl+Shift+O`).

## Set the distance
<!-- target: field:Distance (mm) -->
Type how far out or in the new outline goes, in mm. The work area shows it as you type.

## Choose the direction
<!-- target: field:Direction -->
**Outward** grows the shape, **Inward** shrinks it, **Both sides** makes one of each.

## Choose the corners
<!-- target: field:Corners -->
**Sharp** keeps points, **Rounded** rounds them, **Flat (cut off)** cuts them straight across.

## Keep the original
<!-- target: button:Keep the original shapes -->
Leave it ticked to add the new outline; untick it to replace the original.

## Make it
<!-- target: button:Offset -->
<!-- wait: closed:Offset -->
Click **Offset**. The new outline is selected, on the same layer as the original.
