# Import a drawing
<!-- category: Importing and exporting -->
<!-- summary: Bring an SVG, DXF, PDF, xTool or LightBurn drawing onto the work area. -->
<!-- page: files.md#importing -->
<!-- order: 10 -->
Most designs start in another program: a logo in Inkscape, a part in CAD, a project from xTool Studio.
Importing brings the drawing in at its real size as shapes you can edit, set up and send.

## Pick the layer
<!-- target: panel:Layers -->
Click the layer the drawing should go on. A plain import lands on this layer (files that name their own layers make their own).

## Click Import
<!-- target: ribbon:Import/Import -->
<!-- wait: shapes:+1 -->
Click **Import** (`Ctrl+I`) and choose one or more files in the window that opens. The drawing comes in where the file puts it, or in the middle if it wouldn't fit.

## Read any notes
If something couldn't be brought in, such as text or a hatch, the **Import notes** window lists it and says what to do. Click **OK** to close it.

## Check the size
<!-- target: panel:Selection -->
The new shapes are selected. Check their width and height here: a drawing bigger than the work area must be scaled down before sending.

## Next time: drag it in
<!-- target: canvas -->
You can also drag SVG, DXF, PDF, AI and xTool files from Explorer onto the work area. Hold `Shift` as you drop for a layer per colour.
