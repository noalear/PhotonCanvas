# Go back to an earlier version
<!-- category: Importing and exporting -->
<!-- summary: Open one of the last 20 saved versions of a design. -->
<!-- page: files.md#earlier-versions -->
<!-- order: 70 -->
Each time you save over a design, the version that was there is kept: the last 20 of them.
When an edit went wrong a few saves ago, open the version from before it.

## Save the design
<!-- target: header:Save -->
Versions are kept only for a saved design, one each time you save over it. Click the disk icon (`Ctrl+S`) if you haven't yet.

## Open Earlier versions
<!-- target: header:File -->
<!-- wait: window:Earlier versions -->
Click **File → Earlier versions…**. The list shows when each version was saved, newest first.

## Open one
<!-- target: button:Open as a new design -->
<!-- wait: closed:Earlier versions -->
Pick a version and click **Open as a new design**. It opens untitled; the design's file isn't changed.

## Keep it
<!-- target: header:File -->
To go back to it for good, **File → Save as…** over the original file. To keep both, give it a new name.
