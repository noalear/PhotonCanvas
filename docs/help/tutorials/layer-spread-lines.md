# Spread the lines out
<!-- category: Layers and settings -->
<!-- summary: Burn fill and picture lines out of order so heat can leave between neighbours. -->
<!-- page: layer-settings.md#spread-the-lines-out -->
<!-- order: 180 -->
Burning each line right after the one beside it piles heat into the same place: scorching on wood,
warping on thin plastic, uneven colours on metal. Spreading the lines out burns every few lines
first, then the ones between. On wood pictures it can leave visible rows, so test it first. You
need an Engrave or Picture layer.

## Pick the layer
<!-- target: panel:Layers -->
Click an Engrave layer (with **Lines**) or a Picture layer.

## Spread them
<!-- target: button:Spread the lines out (less heat) -->
Under **More settings**, tick **Spread the lines out (less heat)**. Lines about 0.4 mm apart are
burned in each sweep, then the ones between.

## No set pattern
<!-- target: button:…in no set pattern (no rows) -->
Tick **…in no set pattern (no rows)** to burn them in no regular order, each still far from the
last, so no repeating rows can show.

## Compare on scrap
Laser → **Line test** (from the Material tests add-on) burns the same patch with and without spreading, side by side, so you can
see which looks better on your material.
