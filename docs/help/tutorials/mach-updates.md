# Check for updates
<!-- category: Machine and settings -->
<!-- summary: Be told when a new version is out, or check now. -->
<!-- page: machine.md#updates -->
<!-- order: 90 -->
PhotonCanvas can tell you when a newer version is published. It only asks GitHub for the latest
version number; nothing about you or your designs is sent.

## Open Settings
<!-- target: header:Settings -->
<!-- wait: window:Settings -->
Click the gear at the top right.

## Open the Updates page
<!-- target: text:Updates -->
Click **Updates** in the list on the left. It says which version you have.

## Check at start
<!-- target: button:Check for a new version at start -->
Ticked, PhotonCanvas checks each time it starts and tells you when there's a newer version.

## Check now
<!-- target: button:Check now -->
Click **Check now** to ask straight away.
