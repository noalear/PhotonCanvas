# Keep PhotonCanvas up to date
<!-- category: Machine and settings -->
<!-- summary: New versions download by themselves and go in when you close; or check now. -->
<!-- page: machine.md#updates -->
<!-- order: 90 -->
PhotonCanvas downloads new versions by itself and puts them in when you close it. It only asks
GitHub for the latest version; nothing about you or your designs is sent.

## Open Settings
<!-- target: header:Settings -->
<!-- wait: window:Settings -->
Click the gear at the top right.

## Open the Updates page
<!-- target: text:Updates -->
Click **Updates** in the list on the left. It says which version you have.

## Check at start
<!-- target: button:Check for a new version at start -->
Ticked, PhotonCanvas checks each time it starts, and every few hours while it's open.

## Let updates go in by themselves
<!-- target: button:Put new versions in by themselves -->
Ticked, a new version downloads in the background. When it's ready, a button at the bottom left
of the window says so: click it to restart with the new version now, or just carry on and it goes
in the next time you close PhotonCanvas. Unticked, you're asked first.

## Check now
<!-- target: button:Check now -->
Click **Check now** to ask straight away. If the versions are published in a private GitHub
repository, paste a GitHub access key below first (the page says how to make one).
