# Copies along a path
<!-- category: Arranging -->
<!-- summary: Space copies of a shape evenly along a line or round an outline. -->
<!-- page: arrange.md#along-a-path -->
<!-- order: 80 -->
Along a path spaces copies evenly along a curve or round a shape: beads on a line, holes round a
rim, a border of motifs.

## Draw the path
<!-- target: ribbon:Home/Pen -->
Draw the line or shape the copies should follow, with **Pen**, **Ellipse** or another tool. It must
be longer than the shape you copy.

## Select the shape and the path
<!-- target: canvas -->
<!-- wait: selection:2 -->
Select the shape to copy, then `Shift`+click the path. The longest one is taken as the path.

## Open Along a path
<!-- target: ribbon:Arrange/Along a path -->
<!-- wait: window:Copy along a path -->
Click **Along a path**.

## How many
<!-- target: field:Copies -->
Type the number of copies. The line below says how far apart they'll be.

## Turning
<!-- target: button:Turn each copy to follow the path -->
Ticked, each copy turns with the path; unticked, they keep the original's angle.

## The original
<!-- target: button:Remove the original -->
Ticked, only the copies are left.

## Make them
<!-- target: button:Make copies -->
<!-- wait: closed:Copy along a path -->
Click **Make copies**. The path stays; delete it if it shouldn't be marked.
