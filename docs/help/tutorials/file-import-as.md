# Import grouped, in pieces or as a picture
<!-- category: Importing and exporting -->
<!-- summary: Bring a drawing in as one group, as separate pieces, or as one picture to engrave. -->
<!-- page: files.md#import-as-grouped-every-piece-separate-one-picture -->
<!-- order: 30 -->
A plain import brings a drawing in shape by shape. Sometimes you want it as one unit to move around,
every piece loose to rearrange, or as a picture to engrave with dithering.

## Open the Import as menu
<!-- target: ribbon:Home/Import as… -->
Click **Import as…** in the **Bring in** group. Its menu has three choices:

- **Import, each file grouped…**: each file's shapes become one group.
- **Import with every piece separate…**: every outline its own shape, holes too.
- **Import as one picture…**: the drawing drawn into one black picture (0.1 mm pixels).

## Pick a choice and a file
<!-- wait: shapes:+1 -->
Click one, then choose the drawing in the window that opens.

## Look at the result
<!-- target: panel:Layers -->
A grouped or separate import is on the active layer as usual. A picture import is on a picture layer, named after the file.
