# Start designs from a template
<!-- category: Importing and exporting -->
<!-- summary: Keep a design as a template and start new designs from it. -->
<!-- page: files.md#templates -->
<!-- order: 60 -->
A template is a design you start from again and again: a jig outline with its layers set up, a sign blank.
Starting from it gives a new design, so the template never changes.

## Save as a template
<!-- target: header:File -->
<!-- wait: window:Save as template -->
With the design you want to reuse open, click **File → Save as template…**.

## Name it
<!-- target: window:Save as template -->
<!-- wait: closed:Save as template -->
Type a name and click **OK**. The whole design is kept: every page, layer and setting.

## Start from a template
<!-- target: header:File -->
<!-- wait: window:New from template -->
Click **File → New from template…**. If the design on screen has unsaved changes, you're asked about them first.

## Pick and start
<!-- target: button:Start from it -->
<!-- wait: closed:New from template -->
Pick a template and click **Start from it** (or double-click it). A new, untitled design starts from it; **Delete** removes a template you no longer need.
