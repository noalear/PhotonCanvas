# To front and to back
<!-- category: Arranging -->
<!-- summary: Change the order shapes are kept in: which one Subtract cuts from, and the as-drawn cut order. -->
<!-- page: arrange.md#to-front-and-to-back -->
<!-- order: 40 -->
Shapes are kept in the order they were added. That order decides which shape Subtract cuts the
others from (the bottom one), and the cut order on a layer set to As drawn.

## Select a shape
<!-- target: canvas -->
<!-- wait: selection -->
Select the shape to move in the order.

## To back
<!-- target: ribbon:Arrange/To back -->
Click **To back**: it's now first, the bottom shape that Subtract cuts the others from.

## To front
<!-- target: ribbon:Arrange/To front -->
**To front** makes it last instead: cut last on an As drawn layer.
