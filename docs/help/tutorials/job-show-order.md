# See the processing order
<!-- category: Running jobs -->
<!-- summary: Colour every path by when it's marked, to check the order before you run it. -->
<!-- page: running-jobs.md#order -->
<!-- order: 40 -->
The processing order shows which path the laser marks first and which last, and the moves between
them. Use it to check holes are cut before their outlines and to see what a layer's **Order**
setting does. Have something in the design.

## Show the order
<!-- target: ribbon:View/Processing order -->
Click **Processing order** on the **View** tab. Paths turn from blue (first) through green and yellow to red (last); thin
dashed lines are the travel moves.

## Read the key
<!-- target: canvas -->
The key at the top of the work area names the **First** and **Last** colours and counts the paths.
A dashed orange box shows the job's outer edges.

## From the job bar
<!-- target: button:Order -->
**Order** in the job bar is the same switch. Click it to hide the order again.
