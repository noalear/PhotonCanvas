# Circular array
<!-- category: Arranging -->
<!-- summary: Copies of the selection round a centre: a full ring or an arc. -->
<!-- page: arrange.md#circular-array -->
<!-- order: 70 -->
A circular array repeats a shape round a centre: petals, spokes, numbers round a dial. The copies
show on the work area as you set the numbers.

## Select what to copy
<!-- target: canvas -->
<!-- wait: selection -->
Select the shape or group to repeat.

## Open Circular array
<!-- target: ribbon:Arrange/Circular array -->
<!-- wait: window:Circular array -->
Click **Circular array**.

## How many
<!-- target: field:Copies -->
**Copies** is the total, the original included.

## The centre
<!-- target: field:Centre X -->
**Centre X** and **Centre Y** are the point they go round, in mm. It starts below the
selection, as far below its bottom edge as the selection's longer side, so the copies make a
ring.

## How far round
<!-- target: field:Spread (°) -->
360 spreads them all the way round; less makes an arc from the original.

## Turning
<!-- target: button:Turn each copy to follow the circle -->
Ticked, each copy turns like a spoke; unticked, they all keep the original's angle.

## Make them
<!-- target: button:Make copies -->
<!-- wait: closed:Circular array -->
Click **Make copies**.
