# Turn the lines each pass
<!-- category: Layers and settings -->
<!-- summary: Turn an engraving's lines a little more on every pass and every run, so no stripes build up. -->
<!-- page: layer-settings.md#turning-the-lines -->
<!-- order: 170 -->
When an engraving is done in several passes with the lines always the same way, the line pattern
builds up into stripes or ridges. Turning the lines a little on every pass spreads them out. You
need an Engrave layer with **Fill style** set to **Lines**.

## An Engrave layer
<!-- target: button:Engrave -->
<!-- wait: layer-mode:Fill -->
Select the layer and click **Engrave**.

## Several passes
<!-- target: panel:Layer settings -->
Set **Passes** to 2 or more.

## Turn per pass
<!-- target: field:Turn per pass (°) -->
Under **More settings**, **Turn per pass (°)**: how much further each pass turns. An odd angle like
37° or 23° spreads the angles best. 0 = every pass the same.

## From run to run
<!-- target: button:Keep turning from run to run -->
Tick **Keep turning from run to run** if you run the same job again on the same piece: each run
carries on turning where the last one stopped.

## Start the count again
<!-- target: button:Start again -->
The runs are counted under it. **Start again** counts from 0, so the next run starts at the scan
angle as set.
