# Find help in the program
<!-- category: Getting started -->
<!-- summary: The help guide and F1, right-click help, the tutorials, the getting started tour and the tips. -->
<!-- page: workspace.md#the-help-menu -->
<!-- order: 20 -->
Help is always a click away: the guide explains every button and setting, and the tutorials walk
you through each feature.

## The Help menu
<!-- target: header:Help -->
Click the **?** at the top right. It holds the guide, the tutorials, the getting started tour,
the shortcuts and the safety notice.

## The guide
<!-- target: header:Help -->
**Help guide** (or `F1`) opens this guide. Search it with `Ctrl+F`; links go to other pages and
start tutorials.

## F1 in any window
Press `F1` in any other window of the program: the guide opens at the page about that window.

## The getting started tour
<!-- target: header:Help -->
<!-- wait: window:Getting started -->
Choose **Getting started** in the Help menu to see the first-start tour again, with the
connection setup.

## Right-click anything
<!-- target: ribbon:Home/Text -->
Right-click any button, setting or shape, here **Text**: **See help** opens the guide on it,
**See tutorial** starts its tutorial, and **Disable add-on** turns off the add-on that made it.

## Tips
<!-- target: tab:Home -->
Hover over any button or setting for a tip saying what it does.
