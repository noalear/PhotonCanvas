# Edit several layers at once
<!-- category: Layers and settings -->
<!-- summary: Change a setting on many layers together, copy settings from one layer to another, and merge layers. -->
<!-- page: layers.md#the-active-layer-and-editing-several-layers-together -->
<!-- order: 40 -->
Designs often have several layers that should share a setting: the same speed, the same material,
the same focus. Editing them together, or copying one layer's settings to others, saves setting
each one by hand. You need at least two layers (press `Ctrl+L` to add one).

## Select several layers
<!-- target: panel:Layers -->
Click one card, then `Ctrl+click` another. `Shift+click` selects every layer between.

## Change them together
<!-- target: field:Power % -->
Type a power. It goes to every selected layer. A box that says **mixed** keeps each layer's own
value until you type in it.

## Copy one layer's settings
<!-- target: panel:Layers -->
Right-click a single layer whose settings you like and choose **Copy settings**.

## Paste them
<!-- target: panel:Layers -->
Right-click another layer and choose **Paste settings**. If that layer is among the selected ones,
all of them get the settings, mode included.

## Merge layers
<!-- target: panel:Layers -->
With two or more layers selected, click the merge icon at the top (**Merge selected layers into the
top one**). All their shapes go onto the topmost of them, which keeps its settings.
